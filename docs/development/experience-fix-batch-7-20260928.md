# 操作体验修复批次 7：打印与导出对齐

日期：2026-09-28

范围：N-7；本地实现与验证，未部署生产或 UAT。

## 本批改动

- 收货查询与配送单查询新增 Excel 导出；导出复用列表查询的权限、租户范围和筛选条件，最多导出 10,000 条。
- 入库记录与单据审核新增 CSV 导出；前端按当前已应用筛选分页读取全部结果，不再只导出当前页，并对 Excel 公式注入做转义。
- 上游采购的收货单、差异单、对账单、合同和采购退货单补齐“打印 / 保存 PDF”。差异单打印包含必填举证材料；打印时复制目标单据为独立打印节点，避免长页面因隐藏原布局而产生空白页。
- 供应链账务的账期、对账单、发票三个页签新增 CSV 导出，包含 BOM、引号/换行转义、公式注入防护；Blob URL 延迟回收以兼容 Safari/WebView。
- 厨师长采购单详情新增送货单打印入口，沿用厨师长角色内可访问的路由，不借用受供应商权限保护的页面地址。
- 库存管理工作台新增“打印当前筛选结果”：服务端使用同一筛选契约返回完整匹配结果，打印不受屏幕分页限制。

## 安全与业务边界

- 所有服务端导出继续执行原列表权限、数据范围和租户隔离，不新增越权读取路径。
- CSV 中以 `= + - @` 或制表符开头的用户可控文本加前导单引号，避免被 Excel 当作公式执行。
- 打印、导出均为只读能力，不改变采购、收货、库存、结算状态机。
- 管理工作台仅在显式 `print=1` 时绕过分页，并保留所有当前筛选条件；普通查询行为不变。

## 独立审查修正

- 补回差异单打印中的强制举证材料，避免纸质/PDF 单据缺少证据。
- 账务 CSV 的 Blob URL 从立即回收改为下载后延迟 5 秒回收，兼容 Safari 与 WebView。
- 采购打印从 `visibility` 隐藏整页改为克隆目标单据单独打印，并增加真实 DOM 行为测试，消除长页面空白页风险。
- 补齐管理工作台打印结果的生成时间类型。
