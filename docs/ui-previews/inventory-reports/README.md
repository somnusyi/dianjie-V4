# 库存报表交互预览 · DianJie v1.1.0

2026-09-21，根据用户提供的《库存报表.xlsx》Sheet1 A1:F42 制作。当前阶段为待用户确认的 UI 原型，未接入业务 API、数据库或远程环境。所有记录均为人工构造示例，不是 UAT 或生产数据。

## 本地查看

在本目录运行 `python3 -m http.server 3211 --bind 127.0.0.1`，访问 `http://127.0.0.1:3211/`。仅使用静态 HTML/CSS/JS，不需要项目依赖、账号或数据库。

## 交互与布局

- 沿用项目奶米背景、琥珀色、墨褐文字、圆角和左侧工作区结构。
- “货品与仓库 → 库存与单据”支持移入展开、移出 150ms 后收起；进入浮层取消收起。支持点击、键盘焦点、Escape 和窄屏切换按钮。
- 5 张报表使用独立 hash 地址，多标签切换，表格占据剩余视口。表头和物品标识固定，宽表横向滚动。
- 查询、重置、高级筛选、排序、分页、列显隐、密度、专注模式、CSV 示例导出可交互。其他业务导航仅作布局参照。
- 示例金额可合计；不同单位的数量不跨单位合计；单价不简单求和。

## Excel 字段映射

| 报表 | Excel 行 | 处理 |
|---|---|---|
| 实时库存查询表 | 1–12 | 保留物品类别、单位、单位换算、机构名称、仓库、库存量、库存金额、均价、预计入库、预计出库；可查询、展示及导出。不加入周期统计字段、物品重量。 |
| 出入库明细表 | 13–25 | 保留上游单据号/类型、原因类型、调整单标识、对方机构、上游单据日期、出入库日期；逐物品明细；金额仅展示不含税口径。不加入订货标签、统计类型、仓库类型、批次号。 |
| 出入库汇总表 | 26–32 | 默认总部、供应链总仓；保留出入库类型、期初、入库、出库、期末结余。 |
| 机构间调拨明细表 | 33、35、37、39、41 | 独立页面，调出成本单价、结算单价、调拨数量、调出金额、调入金额。 |
| 机构间调拨汇总表 | 34、36、38、40、42 | 独立页面，保留上述 5 个核心字段；示例按物品和调出/调入机构汇总，单价加权。 |

物品名称、编码、规格、调拨日期及机构等基础识别字段是本次预览补充的设计，不是 Excel 额外要求。筛选布局、默认日期、预期数量口径和汇总单价规则均待业务确认。财务报表没有提供字段，本轮不扩展。

## 用户确认后进行的前后端联动

1. 将预览设计整合到真实 Next.js 页面、SupplyChainShell 导航和角色权限体系。
2. 按报表建立明确的查询/返回类型，让列表、汇总与导出共享同一套后端查询口径。
3. 核对 WarehouseLedgerBalance / Movement / Reservation、上游采购和内部调拨数据来源。预计入库、预计出库、期初截止时间、不含税金额来源与历史字段缺失必须明确；缺失值不能猜测。
4. 先使用现有模型；需要新增字段时同步加入 Prisma 迁移、历史数据兼容和测试，不以本地测试数据覆盖正式数据。

当前 CSV 仅供预览验证，不代表最终 Excel 导出方案已实现。汇总表的出入库类型筛选目前是演示性口径，正式实现前需确定筛选是否影响期初、期末和期间流水。
