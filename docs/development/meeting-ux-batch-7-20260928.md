# UX 批次 7：打印与导出

## 改动

- 收货、配送、入库记录、单据审核支持当前筛选的全部分页 Excel 导出及打印预览。空结果可导出表头；超一万条要求缩小筛选，缺页或总数变化明确失败，不输出静默截断数据。
- 上游采购收货、差异、对账、合同、退货单增加打印入口；收货和对账读取完整明细。厨师采购单和供应商月度对账增加打印；库存管理工作台复用服务端筛选导出作为打印数据源。
- 供应链账期、对账、发票三页支持 CSV，中文 BOM、引号/换行转义及字符串公式防护。
- 共用独立打印预览层，隐藏应用导航、重复表头、防止行跨页；打印与保存PDF均由用户在系统打印窗口完成，不宣称已自动生成独立PDF文件。

## 验证

API/Web tsc --noEmit通过；API122文件1245项、Web74文件899项通过。新增测试覆盖全部分页、数量限制、总数漂移、缺页、空列表、CSV转义与公式防护、先预览后打印及关闭。无数据库变更。
