# 总仓采购入库价格记忆

- 只为 `/v2/supply-chain/inventory` 的单条和批量手工入库提供只读历史价格；不启用或修改上游功能开关。
- 历史键为租户、商品、供应商与采购单位。候选来自未冲销手工入库单据行及已验收数量大于零的 `POSTED` 上游收货行，按实际入库/过账时间择最近；单位不相同不比较。上游候选只接受人民币、价税合一事实，避免把外币或未税合同价写入日常入库总额。
- 单条按历史单价和数量自动联动总额，采购单价与总额均可编辑；批量仅自动填从未被人工触碰的行。单条和行金额均记录自动/手工来源，所以切换供应商时旧自动值会清空，迟到响应不会覆盖当前供应商、商品或人工输入。
- 请求最多包含 200 个去重商品 ID（原始参数最多 10KB）。读取依托现有单据/收货的租户、商品和供应商时间索引；为避免以全局 `take` 截断冷门商品，服务按请求商品集读取并在内存按完整复合键择最新，后续数据规模需要另行引入按每商品窗口的 SQL 查询。
- 未找到历史时保持空白，并显示“无历史采购价”；既有后端单条总金额和批量金额权威口径不变。
