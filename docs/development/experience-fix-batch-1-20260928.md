# 操作体验修复批次 1（2026-09-28）

## 范围

- 老板首页不再向 BOSS 展示无权限的净利总览、建店资金入口；权限边界未放宽。
- 门店订货单查询及 Excel 导出删除与期望到货日重复的预计到货日。
- 供应商订单将取消单从已完成页签移出，新增独立的已取消页签；该页签直接按 `CANCELLED` 请求服务端分页，避免取消单排在第 50 条之后时漏单。
- 门店调拨的发货、收货、撤回均先通过 `ConfirmSheet` 确认；请求中禁止遮罩关闭和重复提交，失败信息在确认层内可见。
- 删除厨师长采购、厨师长库存、供应链工作台中没有任何点击行为的装饰按钮。

## 验收口径

- BOSS 在老板首页和“我的”页都看不到两个无权访问的入口，其他获准角色仍保留入口。
- 订货单页面和导出都只保留一个到货日期字段，后续列次序不发生错位。
- `CANCELLED` 只进入已取消页签，不进入已完成页签。
- 调拨状态接口只能在确认层确认后触发；接口失败时确认层保留并展示页面提示。
- 页面不再保留无 `onClick` 的伪操作按钮。
