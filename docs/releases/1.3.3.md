# 1.3.3

正式版和测试版均已发布。代码与数据分开交付，本次没有导入本地测试数据、测试账号或模拟订单。

## 本轮变化

- 门店订货、独立补货提交后预占库存，撤回或取消释放，接单不重复占用。
- 门店调拨按实际发出、实收、完好退回及损坏登记数量和成本。
- 手工入库、出库、自损、总仓盘点统一为审核改进度，复审后生效；历史单据保留原规则。
- 库存净成本依据原单和流水统计，保留分批收货与退货尾差。
- 采购待办按完整筛选结果汇总；分类、商品返回时保留筛选。
- 三端长列表补搜索，短列表保持原样；精简重复说明，保留原菜单和业务页面结构。
- 修复小数输入、日期范围、中文状态、混合单位合计、表格列偏好、盘点搜索全选及调拨同店选择。
- 系统日期时间默认按北京时间处理，金额显示保留两位小数。
- 质检按商品进货批次维护多张图片，增加未保存关闭保护。
- 送货单使用已确认的竖版表格、库位及分类排序、HarmonyOS Sans 字体；首部只在第一页显示，合并单号自动换行，删除联次和页尾重复收货人、地址。
- 保留已上线的账号申请取消限流，其余接口限流保持。
- 启用分环境安全会话、日志脱敏、新凭据加密及加密备份。关键表每天北京时间02:30，完整备份每月1日02:30。

## 验证与交付记录

当前API、测试前端和正式前端均重新构建；前后端类型检查通过。新增定向回归87项、备份安装器17项通过。两套固定镜像均完成本地业务读取、HTTPS安全会话、错误来源拒绝与退出撤销联验；不是重新执行整套系统所有流程。原有鼠标记录保留其对应源码与镜像身份。

两站实际验证健康、数据库、登录页、申请页、门店公开查询、字体资源、构建标识和其他运行容器隔离。浏览器确认正式与测试默认租户及测试链接分开。新增7项结构更新，不加载本地数据库。
