# 1.3.4-hotfix.3

修复“带入历史采购单”选中后商品不能进入本单。上一版页面要求历史行同时匹配当前有效供货商品和采购单位；测试版最近 12 张 `UT261109-UP-*` 历史单均不能匹配，部分商品当前单位由 kg 改为箱，部分供应商已无有效供货来源。原生下拉框再次选择相同选项也不会触发回填。
