# UX 批次 4：U-2 供应链总仓多人盘点

## 业务路径

盘点管理 → 新建/录入总仓盘点 → 选择仓库、商品、分区及各负责人 → 每人独立保存 → 汇总提交 → 审核。审核事务内调用现有总仓实盘过账，调整余额、批次与流水，同时生成独立盘盈/盘亏记录，进入现有盘盈单、盘亏单列表。零差异也留下盘点过账证据，只有有差异时生成对应盈亏单。支持退回录入、审核前取消；不做反审核。门店盘点和店内置损不变。

复盘差异/打印/PDF 复用已验收页面，使用 `?source=warehouse` 调用总仓复盘数据。多人盘点、盘点、盘盈/盘亏四列表展示总仓来源并直达作业/复盘。

## 默认口径（按指令默认方向执行，待用户复核）

- 写入角色沿用仓库单据：SUPPLY_CHAIN / SUPER_ADMIN / ADMIN / PURCHASER；审核沿用 SUPPLY_CHAIN / SUPER_ADMIN / ADMIN / FINANCE。每个分区只有指定负责人可录入，所有负责人均须属于本租户仓库写角色。
- 一张单属于一个仓库，多仓分别建单；每个商品只能属于一个分区，防止重复汇总。每单最多200项，超出按分区另开单。
- 盘点创建冻结账面版本和均价。已有库存沿用均价；无成本盘盈需经办人填写正成本。金额全程 Prisma.Decimal。
- 盘点期间相关商品须暂停出入库。审核发现账面版本变化，整单409回滚，需取消重建；不覆盖期间业务。实盘低于已预留库存时拒绝审核。
- 分区乐观版本防覆盖，盘点单锁+Serializable事务+冲突重试确保提交/审核幂等；P2034/P2002/P2010-40001耗尽后统一409中文提示。
