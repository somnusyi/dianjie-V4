# UX 批次 3：U-1 合同复用与下单直通

## 核实与改动

模型 `UpstreamSupplierContract.purchaseOrders` 为一对多，`UpstreamPurchaseOrder.contractId` 无唯一约束，一份框架合同可反复引用，未重复建模。下单按供应商选用唯一 ACTIVE 合同，多张才显示选择器；无合同在同一采购面板打开快速创建弹层，保留采购表单，预填供应商、供货关系现行价、日期与可修改的框架合同名称/编号。草稿就地启用并自动带回下单商品。异步供应商切换使用请求序号防止旧价格覆盖。无货源链接商品管理。

默认预填规则按指令默认方向执行，待用户复核：只纳入有效正价，空价由经办人补齐或留空排除；月结、含税、人民币、结算天数 0 沿用原创建默认值。启用必须 ConfirmSheet 核对。

## 验证

API/Web tsc --noEmit 通过；API 122 文件 1245 项通过；Web 限制 2 worker 后完整 70 文件 889 项通过，新增唯一合同、多合同、无合同预填三项交互测试。首次高并发测试出现旧打印/导出计时超时，降低并发后全绿。未改 schema，未部署。
