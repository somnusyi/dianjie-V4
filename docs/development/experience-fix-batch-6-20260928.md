# 操作体验修复批次 6：冗余、文案与状态可见性

日期：2026-09-28

范围：R-1、R-3～R-6、N-4～N-6、N-8、N-10；本地实现与验证，未部署生产或 UAT。

## 本批改动

- 库存管理「其他入库」补齐附件列；采购收货、手工入库、其他入库在单据号旁显示来源徽标，四个列表仍按业务确认口径分开保留。
- 管理表格原“记录信息”弹窗只是重复表格列、没有新增信息，按指令移除无增量入口；盘点单继续保留可进入完整复盘的入口。
- 对账单与合同均保留可点单号，移除旁边重复的“查看来源明细/查看合同内容”同义入口。
- 供应商订单列表移除内嵌到货差异工作台；历史 `?filter=报损` / `?filter=到货差异` 链接转至独立差异页，订单详情中的差异证据区保留。
- 总厨报损页去掉重复的“待督导报损”段，单一明细列表提供“全部 / 待督导·大额”筛选。
- 厨师端底栏及页面统一将“盘点”改为“报损”；库存页明确说明月度实物盘点入口与日常报损入口的区别。
- 总厨争议页删除代码并未执行的“≥¥500”阈值描述。
- 单据审核按钮按权限显示“改单”或“查看”，会计反审核后的单据在列表直接显示“被会计退回”。
- 收货查询的收货单号可展开商品名称、编码和规格，不再必须进入其他页面才能确认行内容。
- 上游采购单超过期望到货日仍未完成时显示逾期天数；供应商待开票订单的应付到期日逾期变红；库存详情的临期/过期批次显示明确警示。

## 业务默认与边界

- R-1 按用户已确认方向不合并四个列表，只补齐来源辨识与附件信息。
- R-5 不虚构不存在的行明细接口；重复表格内容的弹窗直接去掉，有真实增量信息的盘点复盘与单据审核入口保留。
- 供应链角色若从兼容供应商订单页进入差异入口，仍转到供应链收货查询；供应商角色统一进入独立差异页。
- 本批没有改变订单、库存、金额、审核状态机及权限边界。
